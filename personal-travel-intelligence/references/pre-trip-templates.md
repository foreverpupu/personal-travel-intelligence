# Pre-trip comparison views — v1.0

These are **views**, not alternate persistence schemas. For trip-state and decision records use only `travel-data/trips/_templates/trip-state.md`, `travel-data/trips/_templates/decisions.md` and the canonical field contract in `references/data-model.md`. The four starter ledger templates (`trip-state.md`, `decisions.md`, `events.md`, `sources.md`) ship with the separate `travel-workspace-template/`; if these files are absent, ask for the workspace template or generate a minimal ledger based on the data model without pretending the templates were read.
