# Experiment 3: external usability (draft)

**3a — Preinstalled (value):** researcher sets up Skill and a synthetic or explicitly consented private trip workspace, tester only asks a task. Can they use it to create a useful plan or finished post-trip guide? Ask for a completed past trip if no upcoming trip. Record success, perceived value, edits, confusion and desired reuse; do not count help with installation against task success.

**3b — Self-install (friction):** give README and public repo to a separate or clearly labeled tester; no live guidance. Record whether installation succeeds, how long it takes, error messages, and whether referenced files load. Failure here does **not** prove the Skill offers no value once installed.

For each tester: consent to use only the materials they choose; avoid retaining identity, addresses, bookings and photographs in published notes. Do not compare installation success to a revenue conversion metric. If 3a yields no sign of differentiated value, stop at open source and do not build a public app; if 3a is positive but 3b fails, onboarding/host UI is a hypothesis worth examining.
