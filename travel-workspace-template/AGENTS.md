# Personal Travel Workspace (Codex / local agent)

Use the installed `personal-travel-intelligence` skill for travel tasks. Read `travel-data/USER-preferences.md` if provided and authorized, and trip-specific records from `travel-data/trips/<trip-id>/`. Preserve original sources, confirmed bookings, planned-vs-actual distinctions, and provenance. Never invent absent history or live confirmations. Local file writes require user-authorized workspace access; verify each write. ChatGPT Project uploads never auto-sync with this folder. Do not export personal data without permission. For routebook DOCX/PDF, check A4 page size, text parity and visible clipping; state which checks actually ran.


For new trips, copy all four templates from `travel-data/trips/_templates/` into `travel-data/trips/<trip-id>/` before filling state. Keep the private files separate from the distributable Skill folder. For friends-edition output, place detailed source notes in a separate file rather than the reader-facing article. Verify actual PDF page size (A4 ≈ 595 × 842 pt) using code, not an assumed export setting.
