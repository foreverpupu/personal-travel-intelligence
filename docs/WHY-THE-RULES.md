# Why these rules exist / 设计原则

1. **Plan is not actual / 计划不等于实走.** Synthetic example: a traveler planned to enter a lighthouse but found the gate closed. A published guide must say “we did not enter”, even if an intended itinerary listed that attraction.
2. **No invented causes / 不编造原因.** If an attraction was closed, the model should not fill in “due to storm” without source evidence. It can separately suggest possible things to check, clearly labeled as hypotheses.
3. **Respect sunk constraints / 尊重已确认约束.** A nonrefundable hotel is not casually replaced just because a new route looks simpler.
4. **Verified publishing / 成品应实测.** A declaration of “A4 PDF with searchable text” is not verification. Read PDF dimensions, inspect text extraction and render pages before claiming checks passed.
5. **User-owned memory / 资料由用户控制.** A chat statement is not silently persisted to a file. Save or upload confirmed records and verify completion. Personal preferences are not universal rules: they can change with season, companions and trip purpose.

This document contains synthetic illustrations, not real bookings or personal travel records.
